# Second-structure-of-protein-prediction-
Protein secondary structure prediction by PSIPRED and Uniprot
This project presents a bioinformatics assignment focused on protein sequence analysis and secondary structure prediction.

Workflow

1. Protein sequence identification using UniProt
2. Secondary structure prediction using PSIPRED
3. Analysis and documentation of the obtained results
